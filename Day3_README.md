# Day 3 – Sweet Crumbs Home Bakery Chatbot

## Project Description
Today, I worked on building a customer support chatbot for Sweet Crumbs Home Bakery using Groq API and LangChain.

The chatbot is designed to answer customer queries related to bakery products and orders.

## Tasks Completed
- Integrated Groq API with the chatbot.
- Initialized the LangChain chat model.
- Created prompts and chains for generating responses.
- Implemented conversation memory to maintain chat context.
- Tested chatbot responses using a CSV test file (`tests.csv`).
- Created and tested a LangChain agent.

## Technologies Used
- Python
- Groq API
- LangChain
- Google Colab
- CSV

## Learning Outcomes
- Learned how to integrate Groq API with LangChain.
- Understood prompt templates and chains.
- Learned how conversation memory works.
- Practiced testing chatbot responses.
- Understood the basics of LangChain agents.

## Outcome
Successfully implemented and tested the basic customer support chatbot workflow for Sweet Crumbs Home Bakery.
